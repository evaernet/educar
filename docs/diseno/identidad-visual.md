# Identidad visual web

## Referencias aprobadas

- `referencia-login.png`: acceso y registro.
- `referencia-panel.png`: paneles y módulos administrativos.

## Reglas

- Paleta: azul `#0B5EA8`, azul oscuro `#082E65`, turquesa `#00A9B5`, verde `#0A9F91`.
- Fondo con degradado azul–turquesa y ondas sutiles.
- Tarjetas blancas, esquinas amplias y sombras suaves.
- Acciones principales con degradado azul–turquesa.
- Formularios con foco turquesa y contraste accesible.
- Panel administrativo con barra lateral azul oscuro en escritorio.

Las nuevas pantallas deben reutilizar `resources/views/layouts/app.blade.php`.

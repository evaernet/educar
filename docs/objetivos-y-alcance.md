# Objetivos y alcance

## Objetivo general

Desarrollar un sistema web de gestión y, progresivamente, un sitio institucional y una aplicación móvil para centralizar la información académica, deportiva, administrativa y de servicios del Centro Educativo Educar Para Transformar.

## Objetivo SMART

- **Específico:** gestionar alumnos, profesores, configuración académica, inscripciones, servicios y reportes con acceso controlado por roles.
- **Medible:** cada módulo tendrá criterios de aceptación y pruebas automatizadas o funcionales registradas.
- **Alcanzable:** se utilizarán Laravel, MySQL, Blade, Bootstrap, React Native y una API REST según el avance del proyecto.
- **Relevante:** reduce registros manuales, inconsistencias y demoras en la comunicación con la comunidad educativa.
- **Temporal:** la versión lista para testing debe estar finalizada el 11 de noviembre de 2026; el informe y la bitácora de IA se presentan el 17 de noviembre de 2026.

## Límites actuales

El repositorio contiene el sistema Laravel de gestión. El sitio web institucional, la API REST, la aplicación móvil, pagos, deportes, comedor, transporte y reportes todavía no están implementados.

## Criterio de calidad

Cada módulo nuevo debe incluir validaciones de reglas de negocio, rutas protegidas por rol, pruebas y actualización de la trazabilidad e historial de avances.
